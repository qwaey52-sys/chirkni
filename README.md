# Чиркни

Прототип приложения для рисования друг другу обёрнут в Android-приложение через Capacitor. GitHub сам соберёт APK и выложит его в Releases.

## Что внутри
- `www/index.html` — сам прототип (экран рисования + виджет)
- `capacitor.config.json` — настройки Android-обёртки
- `.github/workflows/build-apk.yml` — сценарий, который собирает APK на серверах GitHub

## Как запустить сборку

1. Зарегистрируйся на [github.com](https://github.com), если ещё не зарегистрирован.
2. Создай новый репозиторий (кнопка **New repository**), назови как хочешь, например `chirkni`. Сделай его публичным (Public) — иначе Releases будет видно только тебе.
3. Загрузи в него все файлы из этой папки, сохранив структуру папок (`www/`, `.github/workflows/` и остальные файлы в корне). Проще всего через веб-интерфейс: **Add file → Upload files**, перетащи всю папку.
4. После загрузки зайди во вкладку **Actions** репозитория — сборка запустится автоматически (может занять 3–5 минут).
5. Когда сборка станет зелёной (✓), зайди во вкладку **Releases** справа на главной странице репозитория — там будет файл `chirkni-1.apk` с прямой ссылкой на скачивание.
6. Эту ссылку и кидай в Telegram. Человек откроет её на Android, скачает APK, при установке разрешит "установить из неизвестных источников" (попросит один раз) — и всё готово.

## Важно
- Это debug-сборка для тестов среди друзей, без цифровой подписи для публикации в Google Play — для начала и для Telegram-рассылки этого достаточно.
- Для iPhone этот APK не подойдёт — на iOS единственный официальный способ раздать неопубликованное приложение это TestFlight, который требует платный аккаунт Apple Developer.
- Сам рисунок пока не синхронизируется между разными телефонами по-настоящему — в прототипе оба экрана имитируются на одной странице. Чтобы это заработало между двумя реальными людьми, в `www/index.html` нужно будет добавить подключение к серверу (например, Firebase), который будет пересылать координаты линий между устройствами.
